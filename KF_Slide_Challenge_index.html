Each successful stop earns 25 score points. You never lose points for missing. As your streak grows, the strip moves faster and the target gets smaller.

Your score is for this browser only. It cannot be bought, sold, transferred, withdrawn, or exchanged for Minecraft currency.

How real account linking would work

01 / Sign in

The player creates an account and requests a short one-time linking code.

02 / Verify in Minecraft

The player enters the code in your server. A trusted plugin confirms their Minecraft UUID.

03 / View balance

A secure server API reads the player's Vault/EssentialsX balance and displays it here.

Security note: never put your server console password, RCON password, or API secret in this HTML. Keep those on your backend.
